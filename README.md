# Anuncio S06 · Granada Park

Anuncio de alquiler vacacional del apartamento S06 en el complejo Granada Park (sur de Tenerife), en español e inglés.

- `index.html` (español) y `en.html` (inglés) + `img/`: la web (para GitHub Pages), con selector ES · EN.
- `anuncio-S06.html` / `anuncio-S06-en.html`: la misma web en un solo archivo, con las fotos incrustadas.
- `anuncio-S06.pdf` / `anuncio-S06-en.pdf`: folleto A4 de 3 páginas.
